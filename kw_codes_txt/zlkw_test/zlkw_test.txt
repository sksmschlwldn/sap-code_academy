  DATA : BEGIN OF ls_data,
           mon01 TYPE i,
           mon02 TYPE i,
           mon03 TYPE i,

           mon05 TYPE i,
           mon06 TYPE i,
           mon07 TYPE i,
           mon08 TYPE i,
           mon09 TYPE i,
           mon10 TYPE i,
           mon11 TYPE i,
           mon12 TYPE i,
         END OF ls_data,

         lt_data   LIKE TABLE OF ls_data,

         lv_field  TYPE fieldnam,
         lv_mon(2) TYPE n.

  FIELD-SYMBOLS : <lfv_field> TYPE any.

  UNASSIGN <lfv_field>.

  DO 12 TIMES.

    lv_mon = sy-index.

    CLEAR    lv_field.
    UNASSIGN <lfv_field>.

    CONCATENATE 'LS_DATA-MON' lv_mon INTO lv_field.

* 이구문은 변수나 스트럭쳐의 필드가 Full Name 으로 줘야 한다
    ASSIGN (lv_field) TO <lfv_field>.

    IF <lfv_field> IS ASSIGNED.
      <lfv_field> = 1000.
    ENDIF.

  ENDDO.

  APPEND ls_data TO lt_data.

ENDFORM.
